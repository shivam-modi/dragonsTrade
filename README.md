# 🐉 Dragon Trading Webapp

A browser-based dragon trading game and fund management application built for learning web development concepts.

## Overview

**Dragon Trading Webapp** is an interactive trading simulation game where users manage a virtual fund to buy, sell, and trade dragons. This project serves as a practical learning tool for understanding full-stack web development, real-time data management, and financial trading mechanics.

## Features

- 🎮 **Dragon Trading System** - Buy and sell dragons with dynamic pricing
- 💰 **Fund Management** - Track and manage your virtual investment portfolio
- 📊 **Real-time Updates** - Monitor market changes and dragon values
- 🎯 **Educational Focus** - Learn web development best practices through practical implementation
- 📱 **Responsive Design** - Works across different device sizes

## Tech Stack

- **Frontend**: JavaScript (96.8%), HTML (1.2%), CSS (1.2%)
- **Backend**: Node.js with Express
- **Build Tools**: Shell scripting (0.8%)

## Getting Started

### Prerequisites
- Node.js (v12.0 or higher)
- npm or yarn

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/shivam-modi/dragonsTrade.git
   cd dragonsTrade
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the application:
   ```bash
   npm start
   ```

4. Open your browser and navigate to `http://localhost:3000`

## How to Play

1. Start with an initial fund balance
2. Browse available dragons for trading
3. Make strategic buy/sell decisions
4. Monitor your portfolio performance
5. Compete to achieve the highest returns
